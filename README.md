# 骰游中国：城市合伙人

中国八城旅行＋小店经营桌游，运行于 DSH Web GUI。支持2/4真人联机，朋友输入昵称和六位房号即可加入，不需要审批或独立游戏服务器。

## 朋友如何安装

仓库根目录已经是 DSH bundle，包含构建好的插件，无需朋友安装 Node 或运行构建。

在支持 GitHub/Git 来源安装的 DSH 插件管理中使用下面的安装来源（仓库发布后可用）：

```text
github:AfreedomF/dice-tour-china
```

如果安装界面只接受自然语言，可把下面一句发给 DSH 助手：

> 请使用 plugin_manager 从 github:AfreedomF/dice-tour-china 安装骰游中国插件。先检查已有安装；不要安装依赖构建脚本。

也可以在 GitHub 仓库点 Code → Download ZIP，完整解压，再让 DSH 助手用解压后的仓库根目录绝对路径执行 install_bundle。不要只复制一个 client.js。

没有 DSH 的朋友可下载 Releases 中的浏览器客户端ZIP，完整解压打开 index.html；也可使用仓库 dist/browser 的完整副本。这里只提供静态文件，不需要部署游戏后端。

安装后刷新 DSH，点击侧栏底部骰子入口。你创建2/4人房，把六位号发给朋友；朋友填昵称和房号加入，全部真人准备后房主开始。双方使用相同 Broker，默认地址不必修改。

**0.1.1 默认房号直入。旧版密钥房需新建房才使用新流程。** 请让所有朋友用相同新版客户端。

## 网络与使用

- EMQX 只转发 MQTT 消息；房主客户端运行规则引擎，无需购买或部署独立权威游戏服务器。
- 默认 `wss://broker.emqx.io:8084/mqtt`，可改 WSS Broker 及可选用户名/密码。密码仅内存；刷新需重新填写。
- 官方公共 Broker 页面：https://www.emqx.com/en/mqtt/public-mqtt5-broker 。它是测试/原型设施，无可靠性或持续免费的保证；不承诺所有地区稳定。
- **0.1.1 起默认六位房号直入**：房主创建 2/4 人房，把六位房号发给朋友；朋友填昵称和房号直接加入，不需要密钥、JSON 或房主同意。双方须使用新版客户端及相同 Broker。满员或已经开局拒绝新身份加入。
- 旧版保存的高熵密钥房仍按旧规则恢复，不能仅房号加入；要使用简化流程，请创建新房间。
- 异地朋友需要同款 DSH 插件，或 `dist/browser` 完整副本，或可访问的 HTTPS 静态托管地址。**本机 localhost 地址不能直接发给北京、西安等异地朋友使用。** 本项目不注册云账号、不购买服务、不自动上传文件。
- 静态版构建后可尝试直接打开 index.html（传统 IIFE bundle，无远程 React/CDN）；浏览器必须提供 Web Crypto。若 file:// 安全能力受限，应使用可信 HTTPS 静态托管或朋友本机 localhost 静态服务。静态服务仅分发文件，不执行游戏规则，不是必需的独立游戏服务器。
- 所有真人在线、到齐并准备后，房主才能开始。当前玩家先使用最多一张策略卡，再掷骰，处理当前经营地块，结束停留，结束回合。
- 房主需持续在线。掉线暂停，不托管、不自动代打、不做房主迁移。同一浏览器本地身份/最新房主快照可恢复；本地存档失败会明确提示，不能保证崩溃前未保存状态恢复。
- DSH 收起面板仍在线；主动断开停止连接/心跳并保留本地存档。卸载/关闭客户端清理连接、计时器与订阅。切勿在两个标签页同时恢复同一身份/房主快照。

## 规则（首版，不声称已平衡）

- 八城：北京、西安、成都、重庆、广州、上海、杭州、厦门。32 格 = 每城 3 个经营地块 + 始发站 1、事件 3、高铁站 2、商店 1、公园 1。抽象旅行路线不是实际地理或铁路路线；地名为主题，不代表经营真实景区。
- 起始现金 10000；经过起点 +1500；高铁 +200；公园 +300；旅行商店赠随机卡，手牌上限 12。
- 地块价格 `800 + 城市序号*120 + 地块序号*100`（序号从 0 开始）；升级费 `400 + 城市序号*60`；基础租金 `100 + 城市序号*25 + 地块序号*20`。
- 购买为 0 级，最高 3 级；每次停留最多一次购买或升级，不能同一停留连续买+升。租金 = 基础租金 × (1+等级×2)，同城三地归同一人再 ×2；抵押地块不收租。
- 精准 precise：掷骰前选择 1～6；慢游 slow：下次随机 1～3；discount：下次购买/升级五折、未消费保留、不叠加；shield：抵挡下一笔租金、未触发保留；bonus：立即 +500。每回合最多使用一张卡，且只在掷骰前。
- 事件均匀随机四种：+500、旅行开支 350、随机卡、随机卡。每到一个城市经营地块收集该城印章，不重复。
- 可在自己的回合出售建筑（升级费一半）、抵押无建筑地块（地价一半）、赎回（本金的 110%，向上取整）。资金不足支付时按地块顺序自动售建筑和抵押；已抵押土地不能再次凭空变现。仍不足则尽力支付实际现金，破产清除资产/手牌并推进回合。日志保留偿债过程。
- 默认 20 轮；仅剩一个未破产玩家提前结束。净资产 = 现金 + 所有地块原价 + 建筑原价 − 抵押地块完整赎回额（含利息）。优惠购买仍按原价计资产，这只是明确的首版估值，不代表公平性已验证。未破产优先，净资产相同并列排名；印章展示不作为资产平局破局条件。

## 安全边界

按用户明确选择，0.1.1 默认便捷模式不再提供房间准入保密性：分组加密材料从六位房号确定性派生，不是高熵密码；猜中房号的人可能加入空位、观察分组消息或冒充首次房主。没有房主审批或独立可信目录，也不保证全球房号不碰撞；如果遇到同号混淆，请房主另建新房。仅订阅所填号码对应的本游戏 topic，不扫描其他房间。

保留玩家独立签名、后续固定房主身份/epoch、ECDH 定向手牌视图、版本/重放校验，因此普通客人不能仅凭房号伪造已有玩家签名或解密其他客人的定向手牌。但不防恶意房主，不提供独立服务端级反作弊。旧版显式密钥房及其恢复仍兼容，不自动降级。

身份私钥、重连资料、房主存档只存本地，不发布公共 topic；Broker 密码不写入存档。不要分享浏览器存档。公共 Broker 可观察连接和密文元数据，不能保证可用性，也不能抵抗针对 Broker 的阻断。只订阅本游戏当前房号对应的 topic，不扫描、不 retained 敏感数据；便捷模式 topic 可由房号推导，不再称作随机私密。

## 构建与磁盘

在 `D:\RICH\dice-tour-china` 运行：

```powershell
$env:TEMP='D:\RICH\tmp'; $env:TMP='D:\RICH\tmp'
node tools/build.mjs
node --test --experimental-test-isolation=none test/*.test.js
```

工具依赖已位于 tools/node_modules，pnpm 11 的 tools/pnpm-workspace.yaml 配置 `storeDir: D:/RICH/.pnpm-store`。需要重装时从 tools 执行 `pnpm install --ignore-scripts`，不要擅自批准依赖脚本。构建直接调用已有 esbuild 原生 CLI、继承 stdio，避免受限环境子进程捕获管道 EPERM。

构建产物：`plugin` 是持久化 bundle 安装目录；`dist/browser` 是可完整分享的静态客户端。插件使用 DSH 模块加载器提供的 React，静态版自行打包 React；不使用 iframe、不启动替代 GUI。

使用 DSH plugin_manager 对绝对路径 `D:\RICH\dice-tour-china\plugin` 执行 install_bundle（修改当前 profile 需授权）。不手工修改 DSH 配置。安装后查看侧栏底部骰子入口。游戏内容第一版仅中文，元数据提供中文/英文，控件跟随主题。

源码、依赖、构建和可配置 TEMP/TMP 优先 D 盘；不修改全局环境。无法保证 Windows 和 DSH 自身完全不写 C 盘，安装所需 profile/运行时仍使用 DSH 管理的原位置，不移动 DSH 安装、配置或聊天记录。
